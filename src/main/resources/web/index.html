No password yet? In game, run /ezstats register <password>, or use QuickLogin.

In game, run /ezstats quicklogin. It sends you an 8 digit code that works once, for a few minutes. Don't share it.

In game, run /ezstats resetpassword. It sends you an 8 digit code: type it here with a new password (8 to 128 characters, no spaces). Your new password never goes in chat. Every browser you had signed in is signed out.
